# Dependencies

## MoviesApp (iOS)
- `MobileVLCKit` (~> 3.7.3): Secondary player fallback for non-native stream formats.
- `lottie-ios` (~> 4.6.1): Vector animation rendering for empty states.

## MoviesAppTV (tvOS)
- `lottie-ios` (~> 4.6.1): Vector animation rendering for empty states on Apple TV.
- Primary playback is handled natively via Apple's AVFoundation (`AVPlayer` / `AVPlayerLayer`).
